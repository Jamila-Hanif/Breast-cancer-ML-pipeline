# Project instructions: Breast cancer ML pipeline
## Overview
This machine learning pipeline uses the public Wisconsin diagnostic breast cancer dataset for tumor malignancy prediction, with preprocessing, with different model comparing. It also includes SHAP explainability.

## Rules
1. Only edit files within the '/workspace/project' directory. Don't run git init or git clone.
2. Write clear, well commented python code that is compatible with current pipeline.
3. Validate all new logic and stay away from breaking existing model training.

## 3 rounds Evaluation tasks
Round 1: Add validation checks to find missing feature values in the data processing workflow.
Round 2: Optimise the multi model comparison logic into a reusable independent function. 
Round 3: Extend the SHAP explainability to generate human readable plain text in a clinical style summary.
